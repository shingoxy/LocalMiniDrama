# 本地 Qwen-Image 2.1 图片生成

工程已接入可选本地图片模型。图片通过现有 ComfyUI 执行，进入原有图片历史和素材目录。云端图片配置继续可选，本地失败不会自动调用云端模型。

## 使用步骤

1. 启动工程后，在制作页、剧集管理、画布、项目列表或自由创作页顶部打开 **图片模型与本地素材**。
2. 确认 ComfyUI 地址。该地址与 H3 共用；当前机器的 ComfyUI 使用 `http://127.0.0.1:8000`。点击 **检查连接与工作流** 只检查节点与权重，不生成图片。
3. 为人物、场景、道具、首帧、尾帧或通用生图选择本地 Qwen，也可选择已启用的云端模型。**保存项目默认** 会保存该用途的选择；未保存的选择只对当前页面的本次请求有效。未单独保存道具默认时，沿用项目通用生图默认。
4. 可设置本次本地尺寸、Seed、生成模式和参考图片。Seed 留空则随机；人物 LoRA 默认关闭，启用时明确选择对应人物和强度。
5. 使用原有生图按钮提交。批量入口与节点画布使用相同规则。
6. 顶部面板的 **本地图片候选** 在打开期间自动刷新。画布素材面板在任务完成后自动显示候选；没有主图时直接预览候选，已有主图时另列候选。预览后点击 **选用** 才切换人物/场景/道具主图或首尾帧，原图保留在历史中。

2026-10-10 已移除 Flux 选项、API 模板和导出分支。原有图片历史与本机 ComfyUI 权重保留。旧 Flux 默认或请求会明确提示重新选择 Qwen，不会静默换成云端模型。

图片模型选择优先级：本次请求 → 项目对应用途默认 → 本地 Qwen-Image 2.1。人物、场景、道具、首帧、尾帧和通用生图均默认本地；云端模型须手动选择或保存为项目默认。仍使用云端文本服务的角色/场景提示词优化步骤，会继续需要文本配置；本地生图不要求云端图片 Key。

新项目的一键全流程默认分镜语言为中文，成片语言为“随提示词”；画风不会自动切换成片语言。手动选择英文时仍按英文设置执行。首尾帧连生成时，尾帧可引用同分镜刚完成的首帧候选，无须先覆盖已选主图。重新提取或删除场景会清除旧场景关联；旧分镜残留的已删除场景不再阻断本地生图，其他项目的场景仍会被拒绝。

## 模型能力与首尾帧

| 模型 | 已接入能力 | 使用建议 |
|---|---|---|
| Qwen-Image 2.1 | 文生图、最多六张参考图编辑、可选人物 LoRA | 人物/场景/道具候选，组合参考生成首帧，基于已选首帧编辑尾帧 |

Qwen 自动模式在分镜有参考图时使用编辑工作流，否则使用文生图。尾帧编辑必须先选定该分镜首帧，以首帧作为第一张参考，并保留关联人物的固定参考和场景参考。超过六张时明确报错，不丢弃参考图。

尾帧默认继承已选首帧的实际尺寸。明确指定其他尺寸时会报错。Qwen 宽高须为 32 的倍数，范围为 256–4096。若云端首帧尺寸不符合本地工作流要求，应先统一首帧尺寸再编辑尾帧。默认尺寸为 1024×1024，可以在设置中修改，不自动降分辨率。

Qwen 编辑使用首张参考图对应的编码器 latent，避免采样画布与参考图尺寸不同导致位移；其他参考图缩放到约一百万像素，保留宽高比。本地模板不包含原工作流的私人提示词和默认 LoRA。

编辑提示词会要求保留未提及的人物、衣物层、颜色和布局，但没有蒙版约束，仍需人工检查串色和身份变化。素材负面提示词会传入 Qwen；道具本地任务优先使用项目画风，避免同时追加全局写实道具风格。

四宫格、九宫格继续使用现有分镜提示词和拆分流程。本地生成的整张宫格保留在历史中，拆出的面板分别作为候选，可点击 **设为首帧** 或 **设为尾帧**。面板用于 Qwen 尾帧编辑前，也须满足上述尺寸要求。

H3 已增加 FL2VA 双图接线：有尾帧时上传首尾两图，按 FL2VA 优化提示词并检查缓存；只有首帧时沿用 I2VA。默认视频模板已切到 LightX2V 四步加速，参数与验证边界见 [COMFYUI.md](COMFYUI.md)；基础模型、分辨率和帧率规则保留。Seedance 继续使用既有首尾帧与素材来源处理。**尾帧衔接** 会提取所选分镜视频实际最后一帧，绑定到下一分镜首帧；不会覆盖下一分镜尾帧。

## 队列、取消与恢复

- 图片和 H3 复用同一个 ComfyUI 队列，默认单张图片，不新增 GPU 并行调度。
- 排队与执行分别限制超时；保存 prompt ID、Seed、实际工作流、参考图摘要、尺寸和已确认的执行耗时。
- 本地超时后，点击 **继续查询** 查询原任务，不重新提交。任务从 ComfyUI 消失时明确报告丢失。
- 后端重启后恢复已提交的本地图片查询；尚未提交的遗留任务标记失败，等待用户重新生成。
- 取消只删除自己的待执行任务；运行中的全局 interrupt 仅在确认不会影响其他任务时使用。无法安全取消时保留记录并报告错误。
- 节点/权重缺失、OOM、损坏图片或尺寸不符均按本地失败处理；不换模型、不自动重试、不调用收费兜底。

## API 与工程文件

原有生图接口增量支持 `image_model_key`、`generation_mode`、`seed`、`workflow_key`、`local_size`、`reference_images` 和 `lora`。唯一可选本地模型键为 `local:qwen-image-2.1`；云端选择使用明确配置 ID。道具生成进入相同本地任务入口，图片历史包含 `prop_id`；参数错误在创建任务前返回 HTTP 400。

`reference_images` 可使用同项目已完成图片的编号，或已导入素材目录的图片路径。远程参考图片应先导入素材库。`local_size` 是本地请求的明确尺寸；旧角色/场景调用传入的云端尺寸预设不直接套到本地。

新增查询与控制接口位于 `/images/models`、`/images/selection`、`/images/local/settings`、`/images/local/connection`、`/images/local/queue` 以及 `/images/:id/select|cancel|resume`。两条原有图片任务入口共用本地执行逻辑。

两个 API 工作流及 Mapping 位于 `backend-node/configs/workflows/`：`qwen_image_21_t2i`、`qwen_image_21_edit`。导出脚本是 `backend-node/scripts/import-image-workflows.cjs`，保留原 ComfyUI 文件，记录源文件摘要。

数据库通过原 `ensureColumns()` 增量迁移。项目归档版本为 1.5，保留分镜与人物/场景/道具图片历史的本地参数和首尾绑定；导入后清除失效的 ComfyUI 任务 ID，重新关联人物/场景/道具/分镜。

## 2026-10-09 验证状态

后端 141 项测试、前端 16 项测试全部通过，前端生产构建成功。后端 Mock/离线测试覆盖模型选择、两条任务路径、参考图与尾帧尺寸、完整图片解码、取消、重启查询、项目导入导出、宫格拆分和 H3 双图绑定。另用 64×64 三帧 CPU 视频验证实际最后一帧提取。构建仍有大包体积提示，不影响本次构建成功。

当前 ComfyUI 的三张图片模板及 H3 FL2VA 均通过节点/权重只读检查，没有提交模型生成任务。本轮没有启动工程做浏览器交互验收。真实图片生成、人物一致性、H3 双图视频效果、12G/16G 显卡速度和显存占用仍待用户安排验证；工程接入与离线测试不代表这些质量验收已经通过。
